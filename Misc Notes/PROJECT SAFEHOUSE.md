# **OVERVIEW**

Project **SAFEHOUSE** is the official designation for **Room N-07**, a residential safehouse located within Heaven's Blacksite.

Unlike standard personnel quarters, SAFEHOUSE functions as both a residence and a social space for several long-term residents and trusted guests.

The project was designed around one principle:

> **"Make it feel like a home, not a containment chamber."**

To date, Project SAFEHOUSE has been considered one of the most successful long-term residential environments within Aperture Industries.

## **Neko**

The most infamous keycard in Heaven's Blacksite.

Officially, it is a SAFEHOUSE card.

Unofficially...

Nobody knows how.

Additional encrypted credentials continue to appear during routine audits.

Current known permissions include access to numerous engineering workshops, testing bays, fabrication rooms, maintenance corridors, and several research laboratories.

Security has repeatedly confirmed these permissions are genuine.

No unauthorized access logs have been found.

How Neko continuously acquires additional legitimate access keys remains unknown.

---

# **SECURITY MEMO**

Blacksite keycards function similarly to encrypted NFC storage devices, containing multiple digitally signed access credentials.

Forgery has not been demonstrated.

Duplication attempts automatically invalidate cloned credentials.

The system has maintained a perfect operational security record.

Except...

...whatever Neko keeps doing.
