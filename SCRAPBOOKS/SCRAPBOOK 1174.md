# 1. EXECUTIVE SUMMARY

Following the official renaming of the Hell Fire platform to:

> **CEBERUS**

C.O.R.E. has documented an additional configuration capability.

When configured for conventional **12-gauge slug ammunition**, Ceberus can function in a role substantially different from its original intended close-range configuration.

With the appropriate **rail extension kit** installed, an optic may be mounted.

When paired with a suitable scope, the resulting configuration has demonstrated characteristics comparable to a:

> **MID-RANGE DMR**

This does not change the weapon's official classification.

Ceberus remains a limited-production Tachyon Industries shotgun.

It simply happens to be unusually versatile.

---

# 2. SLUG CONFIGURATION

The standard Ceberus configuration was developed around its specialized Hellfire ammunition.

However, the platform remains capable of accepting conventional 12-gauge ammunition.

Slug ammunition changes its practical role considerably.

Instead of distributing multiple projectiles over a short-range area, the weapon becomes optimized around:

> **A single heavy projectile.**

Combined with an appropriate optic, this allows operators to engage targets at substantially greater practical distances than the weapon's conventional configuration suggests.

C.O.R.E. therefore recognizes the following informal configuration:

> **CEBERUS — DMR CONFIGURATION**

This is an operational nickname rather than a separate weapon model.

---

# 3. RAIL EXTENSION KIT

The DMR configuration requires an appropriate rail extension.

The extension provides sufficient mounting space for an optic while preserving the weapon's existing configuration.

Once installed, the operator can mount a conventional scope.

No permanent modification to the Ceberus itself is required.

The kit is considered an **accessory**, not a new Ceberus variant.

---

# 4. OPTIC COMPATIBILITY

A scope can significantly improve the usability of the slug configuration.

The combination of:

> **Ceberus + slug ammunition + rail extension + scope**

produces a weapon capable of filling a middle-distance precision role.

C.O.R.E. testing describes the configuration as:

> **“A shotgun that has decided it wants to be a DMR.”**

Neri reportedly approved the description.

---

# 6. PERFORMANCE ROLE

The slug configuration does not transform Ceberus into a conventional rifle.

Its characteristics remain those of a shotgun platform.

However, its effective employment envelope changes significantly.

C.O.R.E. categorizes the configuration as suitable for:

- intermediate-range engagements;
    
- precision-oriented shotgun use;
    
- designated-support roles;
    
- controlled target engagement;
    
- and operators who apparently refuse to carry a conventional DMR.
    

The weapon retains the general handling characteristics of the Ceberus platform.

---

# 7. LIMITED MERCHANDISE PROBLEM

There is one significant complication.

Custom accessories for Tachyon Industries Limited Merchandise are:

> **Extremely uncommon.**

This applies to:

- Ceberus;
    
- Night Stalker;
    
- Sleight of Hand;
    
- and other limited Tachyon Industries armaments.
    

The weapons were never intended to have a conventional aftermarket.

They are individually produced limited items.

Consequently, operators cannot simply walk into the Armory and request:

> “One Ceberus scope kit, please.”

There is no standard shelf.

There is barely a shelf for the weapons themselves.

# 12. IMPORTANT DISTINCTION

The Ceberus DMR configuration does **not** represent a new production line.

There are still only the existing limited Ceberus units.

The configuration simply demonstrates that the platform can fulfill multiple roles depending on ammunition and accessories.

Current recognized roles include:

### STANDARD CONFIGURATION

> Close-range shotgun

### HELLFIRE CONFIGURATION

> Specialized incendiary projectile platform

### SLUG CONFIGURATION

> Mid-range precision shotgun

### SLUG + OPTIC CONFIGURATION

> Informal DMR-like role

The weapon remains the same.
